01 — 总览

什么是大型语言模型？

大型语言模型（Large Language Models, LLMs）是基于深度学习、尤其是 Transformer 架构构建的 神经网络模型，它们通过在海量文本数据上进行预训练，习得语言的深层模式与世界知识， 从而能够执行文本生成、理解、推理、翻译等多种自然语言处理任务。

涌现能力

当模型规模超过某个阈值后，会展现出训练目标中未明确要求的能力，如链式思维推理、代码生成等，这是 LLM 最令人瞩目的特性之一。

规模法则

模型性能与参数量、数据量、计算量之间遵循幂律关系（Scaling Laws）。更大、更多、更久——这是过去几年 AI 进步的核心驱动力。

通用性

一个 LLM 可以同时处理问答、摘要、翻译、写作、编程、数学推理等数十种任务，无需为每个任务单独训练模型，展现了极强的通用性。

安全对齐

通过 RLHF（基于人类反馈的强化学习）、DPO（直接偏好优化）等对齐技术，使模型输出符合人类价值观，减少有害、偏见和幻觉输出。

02 — 核心架构

Transformer 架构

2017 年 Google 发布的 "Attention Is All You Need" 论文奠定了现代 LLM 的基石。 Transformer 彻底摒弃了 RNN/CNN，完全依赖自注意力机制来建模序列依赖关系， 实现了前所未有的并行训练效率和长距离依赖捕捉能力。

Encoder-Decoder

原始 Transformer

编码器处理输入序列，解码器自回归生成输出。T5、BART 采用此架构，擅长序列到序列任务如翻译、摘要。

Decoder-Only

自回归模型

仅使用解码器，逐 token 自回归生成。GPT 系列、LLaMA、Qwen 均采用此架构，是当前 LLM 的主流选择，推理效率高。

GPT LLaMA Qwen Mistral
Encoder-Only

理解型模型

仅使用编码器，擅长理解任务如分类、NER、语义搜索。BERT 系列是代表，常作为搜索和排序系统的骨干。

BERT RoBERTa DeBERTa

自注意力机制

自注意力是 Transformer 的核心创新。对于序列中的每个位置，它计算该位置与所有其他位置的相关性权重，从而动态地聚合全局上下文信息。

这使得模型能够：

  • 捕捉任意距离的依赖关系，不受序列长度限制
  • 并行计算所有位置，大幅提升训练效率
  • 根据上下文动态调整关注点，实现语义理解

缩放点积注意力
Attention(Q, K, V) = softmax(Q·KT / √dk) · V
Q — 查询向量
K — 键向量
V — 值向量
其中 Q, K, V 由输入 X 通过可学习权重 WQ, WK, WV 线性变换得到。 √dk 缩放因子防止点积值过大导致 softmax 梯度消失。
03 — 训练流程

从预训练到对齐

一个完整的 LLM 训练通常经历四个阶段：预训练 → 有监督微调 → 奖励建模 → 强化学习/偏好优化。 每个阶段的目标和数据都截然不同，共同塑造了模型的能力与行为。

1

预训练 (Pre-training)

在海量无标注文本（互联网网页、书籍、代码、论文等）上训练模型，学习语言的统计规律和世界知识。训练目标是下一个 token 预测（Next Token Prediction）。

数据 万亿级 Token
目标 最小化交叉熵
算力 数千~数万 GPU
↓
2

有监督微调 (SFT)

使用高质量的人工标注指令-回答对，教会模型遵循用户指令、以对话格式回应。这一步将"文本补全器"转变为"指令跟随器"。

数据 数万~数十万条对话
目标 指令遵循
方法 全量/LoRA 微调
↓
3

奖励建模 (Reward Modeling)

训练一个奖励模型（RM），学习对人类偏好的量化评估。RM 输入一对回答，输出哪个更好以及好多少，为后续强化学习提供信号。

数据 人类偏好排序对
目标 偏好预测
损失 Bradley-Terry 模型
↓
4

强化学习 / 偏好优化 (RLHF / DPO)

利用奖励模型作为奖励信号，通过 PPO 等强化学习算法优化策略模型；或使用 DPO 直接从偏好数据中优化，免去 RM 训练步骤。最终使模型输出安全、有用、符合人类价值观。

方法 PPO / DPO / GRPO
目标 对齐人类偏好
效果 更安全、更有帮助

参数高效微调方法

LoRA

低秩自适应：在冻结的预训练权重旁注入可训练的低秩分解矩阵，仅训练 0.1%~1% 的参数，显存需求大幅降低。

r = rank, α = scaling

QLoRA

量化 + LoRA：将基座模型量化至 4-bit 存储，再叠加 LoRA 训练。单张 24GB 显卡即可微调 65B 模型。

NF4 + DoRA + Paged Optimizer

全量微调

更新所有参数，效果上限最高但算力需求巨大。适合有充足算力且需要深度定制的场景。

需要数千 GPU · 数天训练
04 — 应用场景

大模型正在改变什么

LLM 已渗透至各行各业，从软件开发到科学研究，从内容创作到企业决策， 重新定义了人机交互的边界。

代码生成与补全

Copilot、Cursor、Windsurf 等工具让 AI 成为开发者的结对伙伴，自动补全代码、解释复杂逻辑、生成单元测试。

代码审查与调试

自动识别潜在 bug、安全漏洞、性能瓶颈，提供修复建议和代码重构方案，显著降低维护成本。

Agent 自主编程

Devin、SWE-Agent 等 AI Agent 能够自主理解需求、规划方案、编写代码、运行测试、修复错误，端到端完成开发任务。

文献综述与知识提取

快速阅读数百篇论文，提取关键发现、方法对比、实验结果，生成结构化综述，加速科研进程。

假设生成与实验设计

基于已有知识提出新研究假设，设计实验方案，分析数据，在药物发现、材料科学等领域展现潜力。

数学推理与证明

AlphaProof 利用 LLM 辅助数学证明，在 IMO 级别竞赛中达到金牌水平，开启 AI 辅助数学研究新纪元。

写作与内容创作

辅助撰写文章、剧本、营销文案、小说，提供创意灵感、优化表达、保持风格一致性。

多模态生成

GPT-4o、Sora、DALL·E 等模型实现文本到图像、文本到视频的生成，打破创意表达的技术壁垒。

个性化交互

智能客服、虚拟助手、教育辅导、心理咨询等场景，提供有温度、有共情的自然对话体验。

RAG 知识增强

检索增强生成（RAG）让模型基于企业私有知识库回答问题，解决幻觉问题，实现"有据可依"的智能问答。

业务流程自动化

智能合同审查、财务报告生成、客户数据洞察、供应链优化，将 AI 嵌入核心业务流，提升效率与准确性。

决策支持系统

分析市场趋势、风险评估、方案比选，为管理层提供数据驱动的决策建议，降低信息不对称。

05 — 发展时间线

LLM 演进史

从词袋模型到多模态大模型，AI 语言理解经历了怎样的蜕变？

2017

Transformer 诞生

Google 发表 "Attention Is All You Need"，提出完全基于注意力机制的 Transformer 架构，彻底改变 NLP 领域。

2018

BERT & GPT 问世

Google 发布 BERT（双向编码器），OpenAI 发布 GPT（自回归解码器），开创预训练+微调范式，NLP 进入大模型时代。

2020

GPT-3 与涌现能力

OpenAI 发布 1750 亿参数的 GPT-3，展示少样本/零样本学习能力。研究者发现"涌现能力"现象，引发对规模效应的深入探讨。

2021

RLHF 与 InstructGPT

OpenAI 提出基于人类反馈的强化学习（RLHF）方法，发布 InstructGPT，证明对齐技术可以显著提升模型有用性和安全性。

2022

GPT-4 & 多模态

OpenAI 发布 GPT-4，支持文本+图像输入，通过大学水平考试。同年 Stable Diffusion 发布，开源图像生成生态爆发。

2023

开源浪潮 & ChatGPT

ChatGPT 发布引爆全球 AI 热潮。Llama 2、Mistral、Qwen 等开源模型涌现，LoRA 微调成为标配，RAG 架构广泛落地。

2024

推理模型 & Agent 元年

o1/o3 推理模型、Gemini 1.5 长上下文、Sora 视频生成、AI Agent 框架成熟。MoE 架构成为主流，推理成本持续下降。

2025

迈向 AGI

多模态统一、世界模型、具身智能、AI 科学家……大模型正从"语言工具"演化为"通用智能体"，AGI 的轮廓逐渐清晰。
